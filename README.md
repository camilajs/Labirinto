**Projeto Labirinto em Java**

  O objetivo do projeto é criar, em Java, um algoritmo que encontre a saída de um labirinto dado. 
  Ele deve marcar o caminho escolhido com "*" e sinalizar erros como:
    - Mais de uma entrada;
    - Mais de uma saída;
    - Não possuir entradas ou saídas;
    - Ou apesar de possuir entradas e saídas, não possuir um caminho válido.
