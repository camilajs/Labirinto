**Projeto Labirinto em Java**

  O objetivo do projeto é criar, em Java, um algoritmo que encontre a saída de um labirinto dado. Ele deve marcar o caminho escolhido com "*" e sinalizar erros como mais de uma entrada, mais de uma saída, não possuir entradas ou saídas ou apesar de possuir entradas e saídas, não possuir um caminho válido.
